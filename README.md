# Atelier Women's Essentials

A React + Vite bilingual (English/Bangla) storefront for women's t-shirts.

## Run locally

1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Build with `npm run build`.
5. Type-check with `npm run lint`.

The app uses localStorage for the cart, wishlist, reviews, newsletter subscriptions, language preference, and user-added products. No external AI service is required.
